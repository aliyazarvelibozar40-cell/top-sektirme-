# Top Sektirme Discord

1. Discord Developer Portal'da Redirect URL:
`http://localhost:3000/auth/discord/callback`
2. `.env` dosyasını proje klasörüne koy.
3. `npm install`
4. `npm start`
5. `http://localhost:3000`

`.env` içindeki Client ID ve Client Secret Discord Developer Portal > OAuth2 > General > Client Information kısmından alınır. Bot Token veya Public Key kullanılmaz.
